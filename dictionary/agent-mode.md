Agent mode turns a chat into an [[Agent]]: it can read, write and run within its [[Environment]]. Plan or ask modes keep it to reading and proposing.

## Heard in the wild

- Why didn't it edit anything?
- You were in plan mode. Switch to agent mode to let it change files.
