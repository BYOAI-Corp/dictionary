The source is the evidence for a check: a contract, an opinion, a policy, a record. The [[Verifier]] uses only the source given, never outside knowledge, so a [[Verdict]] means the claim does or doesn't follow from that document. A [[Primary source]] beats a [[Secondary source]] whenever one exists.

## Heard in the wild

- What if the source is wrong?
- Then the verdict is right about the wrong document. Choose the source carefully; the check can't fix it.
