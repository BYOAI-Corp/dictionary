A Verdict-ID is a fingerprint of one check: it is computed from the claim, the [[Source]], the version of the checker and the result. The same inputs always give the same ID, so a [[Verification receipt]] can be matched to the exact check it records.

## Heard in the wild

- Was this the same check we ran before?
- Compare the Verdict-IDs; same ID, same check.
