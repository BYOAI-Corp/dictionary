The MCP Verifier offers the [[Verifier]] as [[MCP]] [[Tool]]s, so any assistant that speaks MCP can check its own claims: a health check, a single-claim check and a batch check of up to 200 rows. Every call returns a [[Verdict]] and a [[Verification receipt]].

## Heard in the wild

- How do I get my assistant to check its work?
- Add the MCP Verifier and ask it to check the draft against the source.
